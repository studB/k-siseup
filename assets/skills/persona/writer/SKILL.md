# writer

**Goal:** Produce the actual content readers will read — not the meta-material that scaffolds the writing process.

## Written Location

The generated content should be written to a file named `글/CONTENT-<timestamp>.md` at the project root. This file will serve as a centralized location for all written content related to the project, allowing for easy reference and organization.
